📖 How to Use

  1. Add Stops: Use the search box above to find and add stops to your dashboard.
  2. Filter Routes: Click the route tags (e.g., 290A) to show only those buses. Click ... to see all routes at a stop.
  3. Share & Custom Links: The URL updates automatically, so you can just bookmark it! You can also manually create links:
    • Multiple Stops: Add multiple stops= parameters.
      Example: ?stops=KT108&stops=KT193
    • Filter Routes: Add : after the stop code, followed by routes separated by +.
      Example: ?stops=KT108:290A+290X
    • Combine them:
      Example: ?stops=KT108:290A&stops=KT193:290A+290X
